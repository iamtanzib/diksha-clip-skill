# Inventing concept animations

Each episode covers different topics, so most clips need **concept animations**, not real UI. Use real UI only when the speaker talks about a real, nameable product, page, post or person (then rebuild that UI faithfully, in English).

## From transcript to storyboard (do this in your head, write only the table)
1. Split the clip into **ideas** (usually 3-6 per 45-60 s). Each idea gets one continuous graphic or a stack/full beat.
2. For each idea find its **shape**: what is actually being said?
   - a number / ratio → counters, grids of units, part-of-whole, scales, bars that fill to a threshold
   - a change over time → line that draws, timeline track, before/after split, progress path
   - a process / steps → connected nodes, a path the camera travels along, stacked cards
   - a comparison → two columns that diverge, a balance, a race, versus split
   - a cause → chain reaction, domino, pipes/flow, magnet/attraction
   - a filter / selection → funnel, sieve, spotlight on a few of many, crossing out
   - a person / role / company → profile card, org chart, badge, résumé line, logo-free name plate
   - an emotion / insight → one big typographic statement with a single symbolic object
3. Pick a **metaphor object** that can carry the idea and, ideally, **travel into the next idea** (shared-element transition).
   Plan the whole clip as 1-3 **morph chains** of the same object (what made Clips 4-5 land first time), e.g.
   upload dialog -> feed tile -> highlighted price -> pill on a staircase -> slider -> audience circle -> pyramid base.
   Write the chain in the storyboard (A -> B -> C) so the build has no design decisions left.
4. **Real first, concept second.** If the line names YouTube, a channel, a video, an app or a person, the first beat is that real UI
   rebuilt (real thumbnails/titles/views). Concept objects then grow out of a real element (a thumbnail, a title word, a view count).
5. Map every motion beat to a spoken word.
6. Check `log/used.md`: no concept + motion pair may repeat from the last ~10 clips. Reuse the system (camera, highlights, morphs), not the scene.

## Storyboard table (what you show the editor)
`time · line · layout · graphic idea · motion beats (word → action) · SFX`
Keep each row one or two lines. Mark rows that are new visual devices with ★.

## Variety bank (starting points, mutate them)
dot/people grids · orbit/rings · funnel/sieve · line chart with tag riding the tip · bar race · scale/balance · timeline scrubber · map pins · stacked cards fanning out · checklist ticking · split-flap counter · calendar flipping · inbox/notification stack · chat bubbles · document with highlighter · magnifier over a crowd · ladder/steps · path with milestones · pie that slices out · price tag/receipt · trophy/badge reveal · before→after slider · iceberg (visible vs hidden) · bucket filling/leaking · seesaw · venn overlap · keyhole/spotlight · paper plane path · rocket/thermometer · clock/hourglass · puzzle pieces joining

Each needs the house look: white/blue, DM Sans, soft shadows, camera moves, blur-in, word sync.
